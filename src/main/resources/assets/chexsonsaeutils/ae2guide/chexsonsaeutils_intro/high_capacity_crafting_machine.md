# 归墟

<BlockImage id="chexsonsaeutils:high_capacity_crafting_machine" scale="4" />

<ItemLink id="chexsonsaeutils:high_capacity_crafting_machine" /> 是一个面向
大量样板存储、分页浏览与批量执行的 AE2 合成宿主。

## 主要能力

- 单机提供 `16,384` 个样板槽位。
- 内置界面每页显示 `27` 个样板槽位。
- 支持按输入或输出内容搜索并高亮命中槽位。
- 支持安装 AE2 速度卡。

## 使用方式

放入已编码的合成样板后，可以按页管理本地样板库。
搜索框会在当前机器的样板全集中查找输入或输出，并跳到命中项。

每安装一张 AE2 速度卡，机器内部执行 lane 数都会翻倍。
formal-machine 调度与大请求 planning 聚合由公共配置中的两个开关控制。
